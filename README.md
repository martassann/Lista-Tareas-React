# 📝 Lista de Tareas - React

Aplicación web desarrollada con **React** que permite a los usuarios gestionar sus tareas diarias de forma clara, visual y moderna. Inspirada en el estilo de **Todoist**, esta aplicación cuenta con una interfaz profesional y responsiva que facilita el seguimiento de tareas personales o profesionales.

## 🚀 Funcionalidades

- ✅ Añadir tareas con nombre, fecha de inicio y fecha de vencimiento  
- 📅 Visualización organizada y limpia en formato de tarjetas  
- 🔴 Indicador visual para tareas vencidas  
- 🗑 Eliminar tareas fácilmente con un botón intuitivo  
- 🎯 Diseño centrado, moderno y responsivo  
- 🌈 Estética profesional con fondo pc

## 🛠 Tecnologías utilizadas

- React (Vite o Create React App)
- HTML5 + CSS3
- JavaScript (ES6+)
- Diseño UI inspirado en Todoist
